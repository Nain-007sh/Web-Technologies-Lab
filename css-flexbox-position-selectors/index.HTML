Part 2: CSS Positioning

The dashed grey box is the item's normal place. See where each position type puts the box.

Static (default)

Normal flow. top/left/right/bottom have no effect.

position: static;
Static Box

Relative

Moves the box away from its normal place (dashed), but the space stays reserved.

position: relative; top: 10px; left: 60px;
Relative Box

Absolute

Removed from the flow and placed relative to the nearest positioned parent (the grey area).

.parent { position: relative; }
.box { position: absolute; bottom: 15px; right: 25px; }
Absolute Box

Fixed

Stays glued to the screen. Look at the orange Fixed button at the bottom-left, and scroll.

position: fixed; left: 20px; bottom: 20px;

Sticky

Scrolls normally, then sticks to the top of the screen while its parent card is visible.

position: sticky; top: 0;
Sticky Box (scroll down!)

Keep scrolling: the green bar stays at the top of the screen until this card ends. This extra text just makes the card tall enough to see the effect.

Part 3: CSS Selectors

Universal *

Targets every element on the page.

* { box-sizing: border-box; }

Every element on this page uses border-box sizing.

Element p

Targets all tags of that name.

p { line-height: 1.6; }

All paragraphs get this line height.

Class .note

Targets elements having that class. Reusable.

.note { background: yellow; }

This paragraph has class="note".

ID #special

Targets one unique element.

#special { color: red; }

This paragraph has id="special".

Attribute [type]

Targets elements by attribute value.

input[type="text"] { ... }
input[type="email"] { ... }

Descendant (space)

Targets ALL matching elements inside, however deep.

.outer-box p { ... }

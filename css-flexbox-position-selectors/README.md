# CSS Practice Lab

A web technologies lab project that demonstrates **Flexbox**, **CSS Positioning** and **CSS Selectors** using plain HTML and CSS. Every topic has the CSS code, a short explanation and a live visual demo.

🔗 **Live Demo:** [https://css-lab-by-husnain.netlify.app/](https://css-lab-by-husnain.netlify.app/)

## Topics Covered

**1. Flexbox**
- Flex container and items
- Main axis and cross axis
- flex-direction, justify-content, align-items
- flex-wrap, gap, flex-grow, flex-shrink

**2. CSS Positioning**
- static, relative, absolute, fixed, sticky

**3. CSS Selectors**
- Universal, element, class, ID
- Attribute selector
- Descendant, child, adjacent sibling, general sibling
- Pseudo-class (`:hover`) and pseudo-elements (`::before`, `::after`)

## Project Structure

## How to Run

1. Download or clone this repository.
2. Keep `index.html` and `style.css` in the same folder.
3. Open `index.html` in any browser.

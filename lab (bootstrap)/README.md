# Nova - Bootstrap 5 Lab Project

A responsive one-page website built as a Bootstrap 5 lab practice project.

**Live Demo:** [https://novabootstrap.netlify.app/](https://novabootstrap.netlify.app/)

## Sections

- Navbar (responsive, collapses on mobile, ScrollSpy)
- Hero carousel
- About
- Services (cards)
- Features
- Call to action
- Contact form
- Footer

## Built With

- HTML5
- Bootstrap 5.3 (CDN)
- Bootstrap Icons (CDN)
- Custom CSS (`style.css`)

## Bootstrap Features Used

Navbar, collapse, container, grid system (`col-sm`, `col-md`, `col-lg`), carousel, cards, forms, buttons, badges, spacing, flex, text, border, shadow and background utilities.

## Project Structure

```
├── index.html
├── style.css
└── README.md
```

## How to Run

1. Download or clone the project.
2. Open `index.html` in any browser.
